Declared coverage, including gaps

API & SolidCraft coverage matrix

This matrix is deliberately stricter than code coverage. It states the qualification level appropriate for each public API/capability and the highest dedicated level currently demonstrated.

Public export gaps: 10 · capability gaps: 18

Meaning of GAP: the API may already have unit tests or incidental use, but it does not yet have the dedicated qualification case required by its target level. The gap remains visible until that case exists.
