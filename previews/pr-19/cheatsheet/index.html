SCPF / API reference

SCPF cheatsheet

2D sketches, 3D volumes and native SolidCraft operations.

SCPF is an experimental API: some combinations are not yet supported. Cylinder(d=..., h=...) starts at its base; Patterned/oriented cutter cylinders are centered along their axes. See the examples for supported operations.

2D shapes · sketches

Rectangle2D(width, depth)

XY rectangle whose lower-left corner is at (0, 0).

Rectangle2D(80, 50)

Circle2D(d=... or r=...)

Circle with diameter or radius; use it in a sketch.

Circle2D(d=8).at(12, 25)

Polygon2D(points, plane='XY')

Closed planar polygon; XY, XZ or YZ.

Polygon2D([(0, 0), (40, 0), (0, 30)])

3D shapes · volumes (no suffix)

Box(length, width, height)

Rectangular 3D box; in SCPF it is centered in X/Y and starts at Z=0.

Box(80, 50, 8)

Cylinder(d=..., h=...)

Direct 3D cylinder, positioned by the center of its bottom face.

Cylinder(d=24, h=14).at(40, 25, 8)

Sphere(radius)

3D sphere centered on the origin.

Sphere(20)

Relative placement · experimental

child.attach(parent, parent=..., child=...)

Join two anchor positions. Native output is resolved parameter expressions, not a persistent face constraint.

Cylinder(d=24, h=14).attach(plate, parent=Anchor.TOP, child=Anchor.BOTTOM)

child.attach(parent, parent=Anchor.CENTER, child=Anchor.CENTER)

Align child and parent centers.

Cylinder(d=8, h=12).attach(plate, parent=Anchor.CENTER, child=Anchor.CENTER)

child.attach(parent, parent=Anchor.INNER_BOTTOM)

Place an enclosure feature on the inner floor of a shelled rectangular body.

Boss(d=7, h=12, hole_d=2.5).attach(enclosure, parent=Anchor.INNER_BOTTOM, offset=(X.MIN + 10, Y.MIN + 10))

X.MIN/CENTER/MAX · Y.MIN/CENTER/MAX

Reference each offset coordinate to the matching parent bound instead of manually calculating half-widths.

offset=(X.CENTER, Y.MAX - 6)

cylinder.pattern(count=2, spacing=40, axis=Axis.Y)

Make symmetric repeated cutters. On a plate center this makes two holes at Y = -20 and +20 relative to its center.

Cylinder(d=8, h=12).pattern(count=2, spacing=40, axis=Axis.Y).attach(plate, parent=Anchor.CENTER, child=Anchor.CENTER)

Operations

shape.at(x, y, z)

Place a Circle2D, Rectangle2D or Cylinder; 2D z offsets the sketch plane.

Circle2D(d=8).at(12, 25)

profile.extrude(distance)

Extrude a planar sketch into a 3D solid.

Rectangle2D(80, 50).extrude(8)

Direction.POSITIVE / Direction.NEGATIVE

Named direction enum: positive follows the sketch normal, negative points opposite.

Circle2D(d=8).extrude(8, direction=Direction.NEGATIVE)

a + b

Union/join. An extruded circular sketch or direct Cylinder can join a rectangular base.

plate + Cylinder(d=24, h=14).at(40, 25, 8)

a - b

Difference/cut. Keep the original left-hand solid.

plate - Cylinder(d=12, h=22).at(40, 25, 0)

a & b

Intersection for supported CSG primitives.

Sphere(30) & Box(50, 50, 50)

solid.fillet(radius, edges=Edges.VERTICAL)

Round vertical edges of a supported 3D body. Explicit 3D edge points are also accepted.

plate.fillet(6, edges=Edges.VERTICAL)

solid.shell(thickness, open=Faces.TOP)

Hollow a solid while leaving the selected face open. Faces selects geometry; Anchor remains for placement.

Box(80, 50, 30).shell(2, open=Faces.TOP)

Plastic features

Lip(width=..., height=...)

Native plastic lip placed by a point on a shelled rim face.

Lip(width=1, height=2).at(-39, 0, 30)

SnapFit(...)

Native cantilever snap fit; hook gives the catch direction.

SnapFit(length=14, thickness=1.5, width=6, catch_depth=1, catch_length=2, hook=(0, -1, 0)).at(0, 19, 2)

Boss(d=..., h=..., hole_d=...)

Native screw boss with an optional centre hole.

Boss(d=7, h=12, hole_d=2.5).at(-30, -15, 2)

Rest(width=..., length=..., height=...)

Native support pad placed by its centre on a face.

Rest(width=16, length=24, height=3).at(0, 0, 2)

Run and inspect

python -m scpf model.py --out out.json

Compile commands without starting SolidCraft.

python -m scpf examples/sample-plate/scpf/model.py --out output/sample.json

python -m scpf model.py --connect

Apply commands to an already open, empty SolidCraft GUI document.

python -m scpf examples/sample-plate/scpf/model.py --connect

python -m scpf replay file.json

Execute an existing command JSON unchanged in SolidCraft.

python -m scpf replay examples/bracket/scpf/solidcraft.json
