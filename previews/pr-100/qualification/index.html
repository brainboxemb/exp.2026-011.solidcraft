SCPF Forge verification

Qualification

Every non-trivial Forge feature is traced from Python API through compiler representation and native SolidCraft behaviour. A green unit test alone is not treated as proof that the CAD result is correct.

Source commit: 3adc469970a03ba63af8e90d6644234fa332af6c · SolidCraft 0.30.1

Qualification levels

LevelLayerWhat it proves
Q1Python APIPublic API validation, symbolic values and compiler invariants.
Q2Command contractGenerated SolidCraft command JSON is complete and inspectable.
Q3Native buildSolidCraft 0.30.1 accepts the command plan and saves an editable design.
Q4Native measurementTimeline and actual body measurements match the expected result.
Q5Parametric mutationA saved design re-solves correctly after parameters.change.
Q6Visual artifactA native snapshot makes orientation and placement reviewable.
