One L-profile on all four front corners

Verify that one directional L-profile and one child AnchorFrame are oriented correctly by each of the four semantic front-corner anchors before any parameter scaling is introduced.

1. Forge contract

Public API

Anchor.FRONT_TOP_LEFT/RIGHT and FRONT_BOTTOM_LEFT/RIGHT; one AnchorFrame(origin=(0,0,0), z=(0,-1,0), x=(1,0,0)) with angle=0

Internal Forge model

One fixed rectangular parent plus four occurrences of one LBracket definition; every child uses the same local attachment frame and differs only by the selected parent corner.

SolidCraft lowering

Four rigid joint.create commands: parent corners use topology-backed edge/on/corner origins; each child supplies the same point/z/x local frame and an explicit zero joint angle.

2. Native verification

Expected result

The four 40x40 L bounding boxes occupy the four quadrants immediately inside the parent front-face corners, with the bracket width centred on that face.

Parametric mutation

None in this case. Width/height mutation is deliberately deferred until the four initial corner orientations are proven.

5. Reference models

These comparisons clarify concepts; Forge does not promise API compatibility with them.

  • BOSL2: A single child-local frame should be reusable while the selected parent anchor supplies the different local corner orientations.
  • SolidCraft: A corner joint origin retains the selected face/edge/corner topology and defines a local frame at that corner.

6. Fixture source

"""Four fixed front-corner placements using the minimal L-profile."""


class FrameBlock:
    WIDTH = 120.0
    DEPTH = 30.0
    HEIGHT = 80.0

    def build(self):
        return Box(self.WIDTH, self.DEPTH, self.HEIGHT)


class LBracket:
    WIDTH = 24.0
    ARM_LENGTH = 40.0
    ARM_HEIGHT = 12.0

    def build(self):
        profile = Polygon2D(
            [
                (0, 0),
                (self.ARM_LENGTH, 0),
                (self.ARM_LENGTH, self.ARM_HEIGHT),
                (self.ARM_HEIGHT, self.ARM_HEIGHT),
                (self.ARM_HEIGHT, self.ARM_LENGTH),
                (0, self.ARM_LENGTH),
            ],
            plane="XZ",
        )
        return profile.extrude(
            self.WIDTH,
            direction=Direction.SYMMETRIC,
        )


class FourCornerL:
    def build(self):
        frame = FrameBlock()
        bracket = LBracket()

        # The neutral L occupies +X and -Z from this local corner. Its
        # attachment normal is +Y. The parent corner frame must rotate those
        # two in-plane directions to the two inward edges at each corner.
        mount = AnchorFrame(
            origin=(0, 0, 0),
            z=(0, -1, 0),
            x=(1, 0, 0),
        )

        top_left = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_TOP_LEFT,
            child=mount,
            angle=0,
        )
        top_right = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_TOP_RIGHT,
            child=mount,
            angle=0,
        )
        bottom_right = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_BOTTOM_RIGHT,
            child=mount,
            angle=0,
        )
        bottom_left = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_BOTTOM_LEFT,
            child=mount,
            angle=0,
        )

        return frame + top_left + top_right + bottom_right + bottom_left
