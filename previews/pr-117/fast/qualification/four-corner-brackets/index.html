Four middle-plane corner brackets

1. Test setup

Test goal

Reuse one simple polygon L-bracket four times around the frame's middle cross-section. This isolates 2D corner position and clocking before moving the same component to the eight physical box corners.

Pass criteria

Four small L-brackets form one ring through the centre of the frame depth. Their inside corners follow the left/right and top/bottom frame edges and the brackets are centred around Y=0.

Mutation criterion

Resize the saved frame from 320x120x160 mm to 400x160x200 mm; the four brackets must remain on the middle plane and follow the moved X/Z edges without rerunning Python.

2. Implementation under test

Fixture source

"""Four simple L-brackets around the frame's middle cross-section."""


class FrameBlock:
    _width = 320.0
    _depth = 120.0
    _height = 160.0

    def build(self):
        return Box(self._width, self._depth, self._height)


class CornerBracket:
    ARM_LENGTH = 36.0
    WALL = 8.0
    THICKNESS = 8.0

    def build(self):
        # Qualification geometry only: one plain L polygon in local XZ.
        # The local inside corner at (0, 0, 0) is the attachment datum.
        profile = Polygon2D(
            [
                (0, 0),
                (self.ARM_LENGTH, 0),
                (self.ARM_LENGTH, self.WALL),
                (self.WALL, self.WALL),
                (self.WALL, self.ARM_LENGTH),
                (0, self.ARM_LENGTH),
            ],
            plane="XZ",
        )
        return profile.extrude(
            self.THICKNESS,
            direction=Direction.SYMMETRIC,
        )


class FourCornerBrackets:
    frame_width = 320.0
    frame_depth = 120.0
    frame_height = 160.0

    def build(self):
        frame = FrameBlock(
            _width=self.frame_width,
            _depth=self.frame_depth,
            _height=self.frame_height,
        )
        bracket = CornerBracket()

        bracket_corner = AnchorFrame(
            origin=(0, 0, 0),
            z=FRONT,
            x=RIGHT,
        )

        # Start at the four FRONT topology corners and move inward by half
        # the current frame depth. This keeps the ring on Y=0 after a native
        # depth change without rerunning Python.
        middle_gap = -(self.frame_depth / 2)

        top_left = bracket.copy().attach(
            frame, parent=Anchor.FRONT_TOP_LEFT,
            child=bracket_corner, gap=middle_gap,
        )
        top_right = bracket.copy().attach(
            frame, parent=Anchor.FRONT_TOP_RIGHT,
            child=bracket_corner, gap=middle_gap,
        )
        bottom_right = bracket.copy().attach(
            frame, parent=Anchor.FRONT_BOTTOM_RIGHT,
            child=bracket_corner, gap=middle_gap,
        )
        bottom_left = bracket.copy().attach(
            frame, parent=Anchor.FRONT_BOTTOM_LEFT,
            child=bracket_corner, gap=middle_gap,
        )

        return frame + top_left + top_right + bottom_right + bottom_left

Public Forge API used

CornerBracket Polygon2D + attach(parent=FRONT corner, child=AnchorFrame, gap=-(frame_depth/2))

Forge model represented by this fixture

One 320x120x160 frame plus four occurrences of one neutral CornerBracket. The bracket is a plain 36x36 mm L-profile with 8 mm wall and 8 mm symmetric thickness.
