Four HUB75-style outside corner brackets

1. Test setup

Test goal

Mount one neutral flat L-bracket on the four outside corners of the front face. This is the direct step after four bottom feet and matches the corner-placement pattern used by the HUB75 frame before adding the rear set.

Pass criteria

Four brackets sit outside the front face: top-left, top-right, bottom-right and bottom-left. Their two equal L arms run inward along the adjacent frame edges.

Mutation criterion

Change frame_width, frame_depth and frame_height from 120x80x60 mm to 160x120x90 mm in the saved .sc design; all four front brackets must follow their moved corners without rerunning Python.

2. Implementation under test

Fixture source

"""Four reusable outside L-brackets on the front corners of a frame."""


class FrameBlock:
    _width = 120.0
    _depth = 80.0
    _height = 60.0

    def build(self):
        return Box(self._width, self._depth, self._height)


class LBracket:
    ARM_LENGTH = 28.0
    WALL = 8.0
    THICKNESS = 4.0

    def build(self):
        # Neutral reusable component in its own local XZ plane.
        # Placement/orientation belongs entirely to the assembly.
        profile = Polygon2D(
            [
                (0, 0),
                (self.ARM_LENGTH, 0),
                (self.ARM_LENGTH, self.WALL),
                (self.WALL, self.WALL),
                (self.WALL, self.ARM_LENGTH),
                (0, self.ARM_LENGTH),
            ],
            plane="XZ",
        )
        return profile.extrude(
            self.THICKNESS,
            direction=Direction.POSITIVE,
        )


class FourCornerBrackets:
    frame_width = 120.0
    frame_depth = 80.0
    frame_height = 60.0

    def build(self):
        frame = FrameBlock(
            _width=self.frame_width,
            _depth=self.frame_depth,
            _height=self.frame_height,
        )
        bracket = LBracket()

        bracket_corner = AnchorFrame(
            origin=(0, 0, 0),
            z=FRONT,
            x=RIGHT,
        )

        top_left = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_TOP_LEFT,
            child=bracket_corner,
        )
        top_right = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_TOP_RIGHT,
            child=bracket_corner,
        )
        bottom_right = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_BOTTOM_RIGHT,
            child=bracket_corner,
        )
        bottom_left = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_BOTTOM_LEFT,
            child=bracket_corner,
        )

        return frame + top_left + top_right + bottom_right + bottom_left


FourCornerBrackets()

Public Forge API used

attach(parent=Anchor.FRONT_TOP_/BOTTOM_... corner, child=assembly-local AnchorFrame)

Forge model represented by this fixture

One parametric frame plus four occurrences of one neutral LBracket definition. LBracket contains only local XZ geometry; the assembly owns which front corner each occurrence uses.
