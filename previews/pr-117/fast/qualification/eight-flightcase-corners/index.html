Eight proportional flightcase corner protectors

1. Test setup

Test goal

Replace the flat L-bracket with a genuinely wrapping three-face protector. One neutral protector is reused at all eight box corners.

Pass criteria

Each protector truly wraps three adjacent case faces: 80 mm along X, 30 mm along Y and 80 mm along Z, with 6 mm material extending outside the case surfaces.

Mutation criterion

Resize the saved case to 400x160x400 mm; protector reach updates natively to 100x40x100 mm and all eight attachment points follow the moved corners.

2. Implementation under test

Fixture source

"""Eight proportional three-face flightcase corner protectors."""


class CaseBlock:
    _width = 320.0
    _depth = 120.0
    _height = 320.0

    def build(self):
        return Box(self._width, self._depth, self._height)


class FlightcaseCorner:
    x_arm = 80.0
    y_arm = 30.0
    z_arm = 80.0
    THICKNESS = 6.0
    OVERLAP = 0.5

    def build(self):
        x_arm = self.x_arm
        y_arm = self.y_arm
        z_arm = self.z_arm
        t = self.THICKNESS
        overlap = self.OVERLAP

        # Canonical FRONT_TOP_LEFT protector: the case extends inward along
        # +X, +Y and -Z. Three plates genuinely wrap the corner.
        top = Box(x_arm, y_arm, t).move(
            x=x_arm / 2,
            y=y_arm / 2,
            z=t / 2,
        )
        front = Box(
            x_arm,
            t + overlap,
            z_arm + overlap,
        ).move(
            x=x_arm / 2,
            y=(-t / 2) + (overlap / 2),
            z=(-z_arm / 2) + (overlap / 2),
        )
        side = Box(
            t + overlap,
            y_arm,
            z_arm + overlap,
        ).move(
            x=(-t / 2) + (overlap / 2),
            y=y_arm / 2,
            z=(-z_arm / 2) + (overlap / 2),
        )
        return top + front + side


class EightFlightcaseCorners:
    case_width = 320.0
    case_depth = 120.0
    case_height = 320.0

    def build(self):
        case = CaseBlock(
            _width=self.case_width,
            _depth=self.case_depth,
            _height=self.case_height,
        )
        protector = FlightcaseCorner(
            x_arm=self.case_width / 4,
            y_arm=self.case_depth / 4,
            z_arm=self.case_height / 4,
        )

        corner_frame = AnchorFrame(
            origin=(0, 0, 0),
            z=BACK,
            x=DOWN,
        )

        front_top_left = protector.copy().attach(
            case, parent=Anchor.FRONT_TOP_LEFT, child=corner_frame,
        )
        front_top_right = protector.copy().attach(
            case, parent=Anchor.FRONT_TOP_RIGHT, child=corner_frame,
        )
        front_bottom_right = protector.copy().attach(
            case, parent=Anchor.FRONT_BOTTOM_RIGHT, child=corner_frame,
        )
        front_bottom_left = protector.copy().attach(
            case, parent=Anchor.FRONT_BOTTOM_LEFT, child=corner_frame,
        )
        rear_top_left = protector.copy().attach(
            case, parent=Anchor.BACK_TOP_LEFT, child=corner_frame,
        )
        rear_top_right = protector.copy().attach(
            case, parent=Anchor.BACK_TOP_RIGHT, child=corner_frame,
        )
        rear_bottom_right = protector.copy().attach(
            case, parent=Anchor.BACK_BOTTOM_RIGHT, child=corner_frame,
        )
        rear_bottom_left = protector.copy().attach(
            case, parent=Anchor.BACK_BOTTOM_LEFT, child=corner_frame,
        )

        return (
            case
            + front_top_left + front_top_right
            + front_bottom_right + front_bottom_left
            + rear_top_left + rear_top_right
            + rear_bottom_right + rear_bottom_left
        )


EightFlightcaseCorners()

Public Forge API used

FlightcaseCorner three-plate geometry + attach(parent=all 8 corner Anchors, child=AnchorFrame(z=BACK, x=DOWN))

Forge model represented by this fixture

One 320x120x320 case plus eight occurrences of one trihedral protector. Its reach is bound to 25% of the case size per axis: X=80, Y=30 and Z=80 mm.
