External L-bracket on all four front corners

1. Test setup

Test goal

Prove that one reusable flat L-bracket can be mounted fully outside the front face at all four outer corners, with both L arms running inward over the frame, and that every bracket follows its own corner when frame width and height change.

Pass criteria

All four 40x40x4 mm brackets lie completely outside the front face (y=-19..-15 for this frame), touch the frame at y=-15 without penetrating it, and occupy the four inward corner quadrants with the correct mirrored orientation.

Mutation criterion

Change FrameBlock_width from 120 to 160 mm and FrameBlock_height from 80 to 120 mm in the saved .sc design; all four external brackets must remain flush to the front face and follow their own moved outer corner without rerunning Python.

2. Implementation under test

Fixture source

"""Four associative front-corner placements using the minimal L-profile."""


class FrameBlock:
    width = 120.0
    DEPTH = 30.0
    height = 80.0

    def build(self):
        return Box(self.width, self.DEPTH, self.height)


class LBracket:
    THICKNESS = 4.0
    ARM_LENGTH = 40.0
    ARM_HEIGHT = 12.0

    def anchors(self):
        return {
            # Physical mounting datum of the bracket:
            #
            # origin: outside corner of the L that touches the frame corner.
            # z:      points out of the frame's front face (-Y).
            # x:      follows the horizontal arm of the L (+X).
            #
            # The parent corner anchor supplies the rotation/mirroring needed
            # for top-left, top-right, bottom-right and bottom-left.
            "mount": AnchorFrame(
                origin=(0, 0, 0),
                z=(0, -1, 0),
                x=(1, 0, 0),
            ),
        }

    def build(self):
        profile = Polygon2D(
            [
                (0, 0),
                (self.ARM_LENGTH, 0),
                (self.ARM_LENGTH, self.ARM_HEIGHT),
                (self.ARM_HEIGHT, self.ARM_HEIGHT),
                (self.ARM_HEIGHT, self.ARM_LENGTH),
                (0, self.ARM_LENGTH),
            ],
            plane="XZ",
        )
        # The bracket is a flat plate on the outside of the front face.
        # Its attachment frame points toward -Y, so a negative extrusion keeps
        # the complete 4 mm plate outside the parent instead of straddling it.
        return profile.extrude(
            self.THICKNESS,
            direction=Direction.NEGATIVE,
        )


class FourCornerL:
    def build(self):
        frame = FrameBlock()
        bracket = LBracket()

        top_left = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_TOP_LEFT,
            child="mount",
            angle=0,
        )
        top_right = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_TOP_RIGHT,
            child="mount",
            angle=0,
        )
        bottom_right = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_BOTTOM_RIGHT,
            child="mount",
            angle=0,
        )
        bottom_left = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_BOTTOM_LEFT,
            child="mount",
            angle=0,
        )

        return frame + top_left + top_right + bottom_right + bottom_left


FourCornerL()

Public Forge API used

LBracket.anchors() -> {'mount': AnchorFrame(...)}; attach(parent=Anchor.FRONT_..., child='mount')

Forge model represented by this fixture

One parametric rectangular frame plus four occurrences of one external LBracket definition. The bracket publishes one named mount datum; the four parent corner anchors provide the required corner orientation.

These comparisons clarify concepts; Forge does not promise API compatibility with them.

  • BOSL2: A single child-local frame should be reusable while the selected parent anchor supplies the different local corner orientations.
  • SolidCraft: A corner joint origin retains the selected face/edge/corner topology and defines a local frame at that corner.
