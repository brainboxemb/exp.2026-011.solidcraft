SCPF / API reference

SCPF cheatsheet

2D sketches, 3D volumes and native SolidCraft operations.

Only a subset of the generic API is implemented. Older names Rectangle, Circle, Polygon, Box3D, Cylinder3D and Sphere3D are temporary aliases. Legacy Cylinder(height, diameter) is centered vertically; new Cylinder(d=..., h=...) starts at its base. Examples describe the API, not guarantees that every combination of operations is supported.

2D shapes · sketches

Rectangle2D(width, depth)

XY rectangle whose lower-left corner is at (0, 0).

Rectangle2D(80, 50)

Circle2D(d=... or r=...)

Circle with diameter or radius; use it in a sketch.

Circle2D(d=8).at(12, 25)

Polygon2D(points, plane='XY')

Closed planar polygon; XY, XZ or YZ.

Polygon2D([(0, 0), (40, 0), (0, 30)])

3D shapes · volumes (no suffix)

Box(length, width, height)

Rectangular 3D box; in SCPF it is centered in X/Y and starts at Z=0.

Box(80, 50, 8)

Cylinder(d=..., h=...)

Direct 3D cylinder, positioned by the center of its bottom face.

Cylinder(d=24, h=14).at(40, 25, 8)

Sphere(radius)

3D sphere centered on the origin.

Sphere(20)

Cube(size)

A special case of Box with three equal sides, centered on the origin. OpenSCAD also uses cube([x, y, z]) for rectangular boxes.

Cube(50)

Operations

shape.at(x, y, z)

Place a Circle2D, Rectangle2D or Cylinder3D; 2D z offsets the sketch plane.

Circle2D(d=8).at(12, 25)

profile.extrude(distance)

Extrude a planar sketch into a 3D solid.

Rectangle2D(80, 50).extrude(8)

profile.extrude(distance, direction='negative')

Extrude towards negative sketch normal.

Circle2D(d=8).extrude(8, direction='negative')

a + b

Union/join. An extruded circular sketch or direct Cylinder3D can join a rectangular base.

plate + Cylinder(d=24, h=14).at(40, 25, 8)

a - b

Difference/cut. Keep the original left-hand solid.

plate - Cylinder(d=12, h=22).at(40, 25, 0)

a & b

Intersection for supported CSG primitives.

Sphere(30) & Cube(50)

solid.fillet(radius, edges='vertical')

Round four vertical edges of an extruded rectangular base.

plate.fillet(6, edges='vertical')

Run and inspect

python -m scpf model.py --out out.json

Compile commands without starting SolidCraft.

python -m scpf examples/sample-plate/scpf/model.py --out output/sample.json

python -m scpf model.py --connect

Apply commands to an already open, empty SolidCraft GUI document.

python -m scpf examples/sample-plate/scpf/model.py --connect

python -m scpf replay file.json

Execute an existing command JSON unchanged in SolidCraft.

python -m scpf replay examples/bracket/scpf/solidcraft.json
