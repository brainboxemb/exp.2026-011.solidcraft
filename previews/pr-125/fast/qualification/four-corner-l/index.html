Four reusable L-profile corner feet

1. Test setup

Test goal

Mount one neutral L-profile foot below each corner of a rectangular frame. The feet belong to the bottom face, so the assembly places four occurrences by local bottom-face offsets and rotates the same component through the four corner orientations.

Pass criteria

The four feet sit below the frame, one at each bottom corner. Their equal L arms point inward along the two adjacent frame edges and their 30 mm height extends only below the frame.

Mutation criterion

Change frame_width from 120 to 160 mm and frame_depth from 80 to 120 mm in the saved .sc design; all four feet must follow the moved bottom corners without rerunning Python.

2. Implementation under test

Fixture source

"""Four reusable L-profile feet mounted under one rectangular frame."""


class FrameBlock:
    _width = 120.0
    _depth = 80.0
    HEIGHT = 60.0

    def build(self):
        return Box(self._width, self._depth, self.HEIGHT)


class CornerFoot:
    ARM_LENGTH = 28.0
    WALL = 8.0
    HEIGHT = 30.0

    def build(self):
        # Neutral reusable component.
        #
        # The local origin is the outside top corner of the foot.
        # The L-shaped footprint extends in local +X/+Y and the foot extends
        # downwards in local -Z. It has no knowledge of the frame or of which
        # of the four frame corners it will occupy.
        footprint = Polygon2D(
            [
                (0, 0),
                (self.ARM_LENGTH, 0),
                (self.ARM_LENGTH, self.WALL),
                (self.WALL, self.WALL),
                (self.WALL, self.ARM_LENGTH),
                (0, self.ARM_LENGTH),
            ],
            plane="XY",
        )
        return footprint.extrude(
            self.HEIGHT,
            direction=Direction.NEGATIVE,
        )


class FourCornerL:
    frame_width = 120.0
    frame_depth = 80.0

    def build(self):
        frame = FrameBlock(
            _width=self.frame_width,
            _depth=self.frame_depth,
        )
        foot = CornerFoot()

        # Placement belongs to this assembly. All four frames use the same
        # local origin and Z direction; only local X changes to express the
        # required clocking. The reusable CornerFoot itself remains neutral.
        bottom_frame = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.DOWN,
            x=Anchor.FRONT,
        )

        front_left_origin = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.UP,
            x=Anchor.FRONT,
        )
        front_right_origin = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.UP,
            x=Anchor.LEFT,
        )
        back_right_origin = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.UP,
            x=Anchor.BACK,
        )
        back_left_origin = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.UP,
            x=Anchor.RIGHT,
        )

        half_width = self.frame_width / 2
        half_depth = self.frame_depth / 2

        # SolidCraft's BOTTOM frame uses local X along world -Y and local Y
        # along world -X. Express the four positions in that local (u, v)
        # frame; no extra joint angle is required.
        front_left = foot.copy().attach(
            frame,
            parent=bottom_frame,
            child=front_left_origin,
            offset=(half_depth, half_width),
        )
        front_right = foot.copy().attach(
            frame,
            parent=bottom_frame,
            child=front_right_origin,
            offset=(half_depth, -half_width),
        )
        back_right = foot.copy().attach(
            frame,
            parent=bottom_frame,
            child=back_right_origin,
            offset=(-half_depth, -half_width),
        )
        back_left = foot.copy().attach(
            frame,
            parent=bottom_frame,
            child=back_left_origin,
            offset=(-half_depth, half_width),
        )

        return frame + front_left + front_right + back_right + back_left


FourCornerL()

Public Forge API used

attach(parent=assembly-local bottom AnchorFrame, child=assembly-local AnchorFrame, offset=(u, v)); parent uses z=Anchor.DOWN/x=Anchor.FRONT and child X uses FRONT/LEFT/BACK/RIGHT

Forge model represented by this fixture

One parametric frame plus four occurrences of one neutral CornerFoot definition. CornerFoot owns only its local L-shaped geometry; the assembly owns position and clocking through four explicit AnchorFrames with the same origin/Z and different X directions.

3. Generated SolidCraft relationship

Four planar joint.create commands use an explicit bottom-centre parent frame (origin 0,0,0; z=Anchor.DOWN; x=Anchor.FRONT). Parametric (u,v) expressions move to the four corners. Because both sides are explicit AnchorFrames, Forge emits mating angle=0 so SolidCraft cannot substitute its optional automatic half-turn.
