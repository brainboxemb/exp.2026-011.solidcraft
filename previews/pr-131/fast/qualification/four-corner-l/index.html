Four centred L-profiles on corner lines

1. Test setup

Test goal

Place one neutral XZ L-profile on each of the four vertical corner lines of a rounded rectangular frame. All four profiles sit at the middle of the frame depth; this is the simple 4-profile baseline before duplicating each corner line in the 8-profile case.

Pass criteria

One L-profile sits on each top-left, top-right, bottom-right and bottom-left XZ corner line. All four are centred in depth and their two arms follow the adjacent X/Z frame edges.

Mutation criterion

Change frame_width/depth from 120x80 to 160x120 mm in the saved .sc design; the four profiles follow the wider X corner positions while remaining centred around Y=0.

2. Implementation under test

Fixture source

"""Four reusable L-profiles centred on the four XZ corner lines."""


class FrameBlock:
    _width = 120.0
    _depth = 80.0
    _height = 60.0

    def build(self):
        return Box(self._width, self._depth, self._height).fillet(8, edges=Edges.VERTICAL)


class LBracket:
    ARM_LENGTH = 28.0
    WALL = 8.0
    THICKNESS = 4.0

    def build(self):
        # Neutral reusable L-profile in its local XZ plane.
        profile = Polygon2D(
            [
                (0, 0),
                (self.ARM_LENGTH, 0),
                (self.ARM_LENGTH, self.WALL),
                (self.WALL, self.WALL),
                (self.WALL, self.ARM_LENGTH),
                (0, self.ARM_LENGTH),
            ],
            plane="XZ",
        )
        return profile.extrude(
            self.THICKNESS,
            direction=Direction.POSITIVE,
        )


class FourCornerL:
    frame_width = 120.0
    frame_depth = 80.0
    frame_height = 60.0

    def build(self):
        frame = FrameBlock(
            _width=self.frame_width,
            _depth=self.frame_depth,
            _height=self.frame_height,
        )
        bracket = LBracket()

        # Use the same neutral child frame as the eight-profile case.
        bracket_corner = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.FRONT,
            x=Anchor.RIGHT,
        )

        # The FRONT topology gives us the four XZ corner identities. A
        # parametric negative gap then moves each profile along that corner
        # line to the middle of the frame depth. The profile's 4 mm extrusion
        # is centred around Y=0.
        centre_gap = -(self.frame_depth / 2 + LBracket.THICKNESS / 2)

        top_left = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_TOP_LEFT,
            child=bracket_corner,
            gap=centre_gap,
        )
        top_right = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_TOP_RIGHT,
            child=bracket_corner,
            gap=centre_gap,
        )
        bottom_right = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_BOTTOM_RIGHT,
            child=bracket_corner,
            gap=centre_gap,
        )
        bottom_left = bracket.copy().attach(
            frame,
            parent=Anchor.FRONT_BOTTOM_LEFT,
            child=bracket_corner,
            gap=centre_gap,
        )

        return frame + top_left + top_right + bottom_right + bottom_left


FourCornerL()

Public Forge API used

LBracket + four standard FRONT corner anchors; a parametric gap moves each occurrence from the front topology reference to the Y-centre of the same corner line.

Forge model represented by this fixture

One rounded parametric FrameBlock plus four occurrences of one neutral LBracket definition. The bracket owns only its local XZ polygon; the assembly owns which corner line and depth position each occurrence uses.

3. Generated SolidCraft relationship

Four rigid joint.create commands use the four FRONT XZ corner topology references and one symbolic normal offset derived from frame_depth. The offset keeps every 4 mm profile centred around Y=0 after native depth mutation.
