Four centred L-profiles on corner lines

1. Test setup

Test goal

Place one neutral XZ L-profile on each of the four vertical corner lines of a rounded rectangular frame. All four profiles sit at the middle of the frame depth; this is the simple 4-profile baseline before duplicating each corner line in the 8-profile case.

Pass criteria

One L-profile sits on each top-left, top-right, bottom-right and bottom-left XZ corner line. All four are centred in depth and their two arms follow the adjacent X/Z frame edges.

Mutation criterion

Change frame_width/depth from 120x80 to 160x120 mm in the saved .sc design; the four profiles follow the wider X corner positions while remaining centred around Y=0.

2. Implementation under test

Fixture source

"""Four reusable L-profiles centred on the four XZ corner lines."""


class FrameBlock:
    _width = 120.0
    _depth = 80.0
    _height = 60.0

    def build(self):
        return Box(
            self._width,
            self._depth,
            self._height,
        ).fillet(8, edges=Edges.VERTICAL)


class LBracket:
    ARM_LENGTH = 28.0
    WALL = 8.0
    THICKNESS = 4.0

    def build(self):
        profile = Polygon2D(
            [
                (0, 0),
                (self.ARM_LENGTH, 0),
                (self.ARM_LENGTH, self.WALL),
                (self.WALL, self.WALL),
                (self.WALL, self.ARM_LENGTH),
                (0, self.ARM_LENGTH),
            ],
            plane="XZ",
        )
        # Symmetric depth makes the profile naturally centre on a corner line.
        return profile.extrude(
            self.THICKNESS,
            direction=Direction.SYMMETRIC,
        )


class FourCornerL:
    frame_width = 120.0
    frame_depth = 80.0
    frame_height = 60.0

    def build(self):
        frame = FrameBlock(
            _width=self.frame_width,
            _depth=self.frame_depth,
            _height=self.frame_height,
        )
        bracket = LBracket()

        # Assembly-local XZ plane through Y=0. It survives the rounded outer
        # corners because placement is dimensional, not based on a sharp edge.
        frame_xz = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.FRONT,
            x=Anchor.RIGHT,
        )
        bracket_origin = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.FRONT,
            x=Anchor.RIGHT,
        )

        half_width = self.frame_width / 2

        top_left = bracket.copy().attach(
            frame,
            parent=frame_xz,
            child=bracket_origin,
            offset=(-half_width, self.frame_height),
            angle=270,
        )
        top_right = bracket.copy().attach(
            frame,
            parent=frame_xz,
            child=bracket_origin,
            offset=(half_width, self.frame_height),
            angle=180,
        )
        bottom_right = bracket.copy().attach(
            frame,
            parent=frame_xz,
            child=bracket_origin,
            offset=(half_width, 0),
            angle=90,
        )
        bottom_left = bracket.copy().attach(
            frame,
            parent=frame_xz,
            child=bracket_origin,
            offset=(-half_width, 0),
            angle=0,
        )

        return frame + top_left + top_right + bottom_right + bottom_left


FourCornerL()

Public Forge API used

LBracket + one assembly-local XZ AnchorFrame; four planar offsets select the X/Z corner lines and angle=0/90/180/270 clocks the neutral profile.

Forge model represented by this fixture

One rounded parametric FrameBlock plus four occurrences of one neutral LBracket definition. The bracket owns only its local XZ polygon; the assembly owns which corner line and depth position each occurrence uses.

3. Generated SolidCraft relationship

Four planar joint.create commands share one parent XZ frame at Y=0. Symbolic X/Z offsets use frame_width/frame_height, while native joint clocking gives the four L orientations. No sharp corner edge is required, so the 8 mm frame fillets remain valid.
