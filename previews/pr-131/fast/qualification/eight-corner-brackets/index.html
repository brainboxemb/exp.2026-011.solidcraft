Eight L-profiles: two on each corner line

1. Test setup

Test goal

Extend the 4-profile baseline by placing two copies on each XZ corner line: one near the front end and one near the rear end of the frame depth. The eight profiles form four explicit corner pairs.

Pass criteria

Each of the four XZ corner lines carries exactly two L-profiles. At 80 mm depth the front profiles occupy Y=-40..-36 and the rear profiles Y=36..40.

Mutation criterion

Change frame_width/depth/height from 120x80x60 to 160x120x90 mm; each pair follows its X/Z corner and the front/rear profile remains flush inside the new depth limits.

2. Implementation under test

Fixture source

"""Eight vertical L-profiles: two on each rounded side corner."""


class FrameBlock:
    _width = 120.0
    _depth = 80.0
    _height = 60.0

    def build(self):
        return Box(
            self._width,
            self._depth,
            self._height,
        ).fillet(8, edges=Edges.VERTICAL)


class LProfile:
    ARM_LENGTH = 28.0
    THICKNESS = 4.0
    PROFILE_HEIGHT = 16.0

    def build(self):
        profile = Polygon2D(
            [
                (0, 0),
                (self.ARM_LENGTH, 0),
                (self.ARM_LENGTH, -self.THICKNESS),
                (-self.THICKNESS, -self.THICKNESS),
                (-self.THICKNESS, self.ARM_LENGTH),
                (0, self.ARM_LENGTH),
            ],
            plane="XY",
        )
        return profile.extrude(
            self.PROFILE_HEIGHT,
            direction=Direction.POSITIVE,
        )


class EightCornerBrackets:
    frame_width = 120.0
    frame_depth = 80.0
    frame_height = 60.0

    def build(self):
        frame = FrameBlock(
            _width=self.frame_width,
            _depth=self.frame_depth,
            _height=self.frame_height,
        )
        profile = LProfile()

        frame_xy = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.UP,
            x=Anchor.RIGHT,
        )
        profile_origin = AnchorFrame(
            origin=(0, 0, 0),
            z=Anchor.UP,
            x=Anchor.RIGHT,
        )

        half_width = self.frame_width / 2
        half_depth = self.frame_depth / 2
        top_height = self.frame_height - LProfile.PROFILE_HEIGHT

        def placed(x, y, angle, height):
            return profile.copy().attach(
                frame,
                parent=frame_xy,
                child=profile_origin,
                offset=(x, y),
                gap=height,
                angle=angle,
            )

        # Two short vertical angle profiles on each of the four rounded
        # side corners: one at the bottom and one at the top.
        front_left_bottom = placed(-half_width, -half_depth, 0, 0)
        front_left_top = placed(-half_width, -half_depth, 0, top_height)

        front_right_bottom = placed(half_width, -half_depth, 90, 0)
        front_right_top = placed(half_width, -half_depth, 90, top_height)

        rear_right_bottom = placed(half_width, half_depth, 180, 0)
        rear_right_top = placed(half_width, half_depth, 180, top_height)

        rear_left_bottom = placed(-half_width, half_depth, 270, 0)
        rear_left_top = placed(-half_width, half_depth, 270, top_height)

        return (
            frame
            + front_left_bottom + front_left_top
            + front_right_bottom + front_right_top
            + rear_right_bottom + rear_right_top
            + rear_left_bottom + rear_left_top
        )


EightCornerBrackets()

Public Forge API used

the same neutral LBracket and central XZ AnchorFrame as the 4-profile case; each X/Z corner offset is emitted twice with opposite symbolic depth gaps.

Forge model represented by this fixture

One rounded parametric FrameBlock plus eight occurrences of one LBracket definition, organised conceptually as four XZ corner lines with two depth positions per line.

3. Generated SolidCraft relationship

Eight planar joint.create commands reuse the same four X/Z offsets and clocking angles. The normal gap is +(frame_depth/2-2) for the front member of each pair and the negative value for the rear member, keeping the symmetric 4 mm profile inside the rounded frame depth.
