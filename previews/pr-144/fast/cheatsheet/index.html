SCPF reference

Cheatsheet

SolidCraft version: 0.30.1 tested; older versions are refused and newer versions trigger a compatibility warning.

Common SCPF syntax alongside tiny examples that CI compiles. For explanations, examples and limitations, read the full API Guide.

What is verified? The linked examples and API unit tests run in GitHub Actions. Cheatsheet fragments describe API calls; a fragment alone is not a complete runnable model.

Shapes and sketches

Box(length, width, height)

Solid, centered in XY; its bottom is at Z=0.

Box(40, 30, 10)

View working example →

Rectangle2D(width, depth)

Planar XY profile authored inside a Sketch.

with Sketch(plane='XY') as sketch:
    Rectangle2D(100, 60)

View working example →

Circle2D(d=...)

A round 2D profile authored inside a Sketch.

with Sketch(plane='XY') as sketch:
    Circle2D(d=8)

Polygon2D(points, plane=...)

A closed profile on XY, XZ or YZ.

Polygon2D([(0,0), (40,0), (0,30)], plane='XZ')

Cylinder(d=..., h=...)

Direct 3D cylinder, with its base at the placement point.

Cylinder(d=24, h=14).at(0, 0, 8)

Features and placement

sketch.extrude(distance)

Extrude an explicitly authored Sketch into editable native solid history.

with Sketch(plane='XY') as sketch:
    Rectangle2D(80, 50)
plate = sketch.extrude(8)

View working example →

Hole(d=..., depth=...)

A native hole. THROUGH_ALL follows the target body.

Hole(d=8, depth=Depth.THROUGH_ALL)

View working example →

shape.on(target, face=...)

Place a feature on a selected face of another shape.

Hole(d=8, depth=Depth.THROUGH_ALL).on(plate, face=Faces.TOP)

View working example →

shape.pattern(...)

Repeat a supported feature before placing it on its parent shape.

Hole(d=8, depth=Depth.THROUGH_ALL).pattern(count=2, spacing=40, axis=Axis.Y)

View working example →

shape.fillet(...)

Round selected edges of a feature-based body.

body.fillet(2, edges=Edges.VERTICAL)

shape.shell(...)

Create an open-sided shell (supported feature trees only).

Box(80, 50, 30).shell(2, open=Faces.TOP)

a + b / a - b / a & b

Join, cut or intersect supported shapes; operation support depends on the shape types.

body + Hole(d=8).at(0, 0, 10)

Reusable components

model.copy().move(x=...)

Copy an occurrence of one definition; preserve editable feature history.

second = first.copy().move(x=40)

View working example →

model.attach(...)

Fix one reusable component to another through explicit attachment references.

right = Block().attach(left, parent=Anchor.RIGHT, child=Anchor.LEFT)

View working example →

attach(offset=(u, v))

Keep an in-plane attachment offset associative; parameter expressions become native planar-joint values.

part.attach(base, parent=Anchor.FRONT_TOP_LEFT, child=mount, offset=(0, -wall + 12))

View working example →

assembly.with_anchor(...) / anchor(...)

Expose a semantic attachment datum owned by an assembly without adding application-specific anchors to a generic component.

frame = (left + right).with_anchor("front_top_left", left, ref)
parent = frame.anchor("front_top_left")

View working example →

corner anchors

Use one of the eight rectangular corner references when attaching components.

marker = Marker().attach(base, parent=Anchor.FRONT_TOP_RIGHT, child=Anchor.BACK_TOP_RIGHT)

View working example →

AnchorFrame

Define an oriented local attachment frame. Return it from anchors() when the datum belongs to the reusable component, or pass it directly to attach() when it belongs only to the assembly.

mount = AnchorFrame(origin=(0,0,-12), z=(0,1,0), x=(0,0,-1))
part.attach(base, parent=Anchor.FRONT_TOP_LEFT, child=mount)

View working example →

AnchorTopology

Keep a named or assembly-local attachment reference on a planar-face edge or one of its endpoints so SolidCraft can follow changing geometry.

def anchors(self):
    return {"mount": AnchorTopology(edge=(0,10,5), on=(0,10,10), corner=(0,0,5))}

View working example →

model.rotate(axis=..., degrees=...)

Orient a native occurrence; rotation does not alter the shared component.

second = first.copy().move(x=40).rotate(axis=(0,0,1), degrees=180)

Compile and inspect

python -m scpf ... --out

Compile a model to SolidCraft command JSON; no SolidCraft app needed.

python -m scpf examples/simple-box/scpf/model.py --out output/box.json

View working example →

python -m scpf replay ...

Send existing command JSON to an open SolidCraft session; does not recompile.

python -m scpf replay output/box.json

python -m scpf ... --connect

Execute a model in an open SolidCraft GUI document.

python -m scpf examples/simple-box/scpf/model.py --connect
