SolidCraft capability & Forge API map

This is a curated map of user-level CAD capabilities. It deliberately does not mirror SolidCraft's hundreds of individual commands. The goal is to see what the native engine can do, what Forge exposes today, and which gaps matter.

Reference APIs

PythonSCAD is the primary Python ergonomics reference; BOSL2 the main attachment/local-frame reference; OpenSCAD the minimal CSG baseline; and SolidCraft remains the native capability truth.

SolidCraft

Native capability truth

What can remain editable and associative in the actual CAD engine?

Parametric sketches/features, BRep topology, components, occurrences and joints.

PythonSCAD

Primary Python API ergonomics reference

How should ordinary scripted modelling feel to a Python user?

First-class solids, Python methods/operators, composability and the normal Python ecosystem.

BOSL2

Attachment and local-frame reference

How can anchors, orientation and parent-relative placement stay understandable?

Attachables, semantic anchors and explicit local orientation/spin concepts.

OpenSCAD

Minimal CSG and transform baseline

What is the smallest familiar vocabulary for primitives, transforms and booleans?

Simple CSG, transformations, modules and a compact language reference.
