Geometry, sketches and Boolean operations

Solids, 2D profiles, extrusions and the CSG operators.

Start with a solid

Box(length, width, height) is centred in X/Y, with its lower face at Z=0. Cylinder(d=…, h=…) starts at its bottom face. A sphere is specified by radius. These initial coordinate assumptions matter when locating holes or placing multiple components.

from scpf import Box, Cylinder, Sphere

plate = Box(80, 50, 8)
pin = Cylinder(d=8, h=20).at(10, 10, 8)
ball = Sphere(12)

Draw a 2D profile, then extrude it

A Rectangle2D is a planar profile rather than a 3D body. Polygon2D can be placed on the XY, XZ or YZ plane.

from scpf import Rectangle2D, Polygon2D

plate = Rectangle2D(80, 50).extrude(8)
side_profile = Polygon2D(
    [(0, 0), (40, 0), (40, 8), (8, 8), (8, 30), (0, 30)],
    plane="XZ",
    world=True,
)

A profile's plane affects where its axes go; changing the camera does not rotate its geometry. Use a supported extrusion direction to create 3D material.

Add, subtract and intersect

body = Box(50, 50, 20)
tool = Cylinder(d=12, h=22).at(0, 0, 0)
joined = body + tool       # union, where supported
cut = body - tool          # difference, where supported
shared = body & tool       # intersection, where supported

The supported compiler path depends on the operands. Native feature history and CSG trees are not interchangeable for every operation. For manufacturing features such as holes, prefer the native feature operations.
