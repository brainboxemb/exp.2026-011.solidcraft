Construction stages

  1. Base — sketch XY rectangle (80 × 50)
  2. Extrude1 — extrude base by 8 mm
  3. Fillet1 — fillet four vertical corners, R6
  4. Holes — cut two mounting holes Ø8
  5. Boss — join Ø24 boss above plate, height 14
  6. Bore — cut central Ø12 bore through full 22 mm

Python model

@dataclass
class SamplePlate:
    """Build the sample plate from object-level CAD intent."""

    width: float = 80
    depth: float = 50
    thickness: float = 8

    def build(self):
        plate = Rectangle2D(self.width, self.depth).extrude(self.thickness)
        plate = plate.fillet(6, edges=Edges.VERTICAL)

        holes = Hole(d=8, depth=Depth.THROUGH_ALL).pattern(
            count=2,
            spacing=self.width - 24,
            axis=Axis.X,
        ).attach(plate, parent=Anchor.TOP)
        plate = plate + holes

        boss = Cylinder(d=24, h=14).attach(
            plate,
            parent=Anchor.TOP,
            child=Anchor.BOTTOM,
        )
        plate = plate + boss

        bore = Hole(d=12, depth=Depth.THROUGH_ALL).attach(
            plate,
            parent=Anchor.TOP,
        )
        plate + bore
