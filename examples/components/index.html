3 · Reuse a component

Two instances of one Block definition, placed relative to meaningful component references.

Compiled: 13 native commandsNative SolidCraft 0.30.1 render, verified against this source commit.

Python source

class Block:
    length = 40.0
    width = 30.0
    height = 10.0

    def build(self):
        return Box(self.length, self.width, self.height)


class TwoBlocks:
    def build(self):
        left = Block()
        right = Block().attach(
            left,
            parent=Anchor.RIGHT,
            child=Anchor.LEFT,
        )

        return left + right
