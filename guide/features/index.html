Features and references

Native holes, fillets, shells and relative positioning.

A feature changes an existing body

A native feature is different from subtracting arbitrary CSG geometry. SCPF can retain named sketches and operations in SolidCraft history. For exact results, supported body types and selection constraints matter.

Holes

from scpf import Box, Hole, Depth, Anchor

plate = Box(100, 60, 10)
hole = Hole(d=8, depth=Depth.THROUGH_ALL)
plate = plate + hole.attach(plate, parent=Anchor.TOP)

A Hole is a native hole feature: adding it to the shape means adding the operation that removes material. Anchor.TOP indicates its entry face, not a surface normal you can use as an arbitrary coordinate transform.

Fillets and chamfers

from scpf import Box, Edges
body = Box(80, 50, 15)
rounded = body.fillet(3, edges=Edges.VERTICAL)

Edge selection can use supported named selectors or explicit pick coordinates. Named profile segment IDs are available for Polygon2D workflows. A topological edge cannot always be inferred reliably from a visual camera position.

Shells

from scpf import Box, Faces
case = Box(80, 50, 30).shell(2, open=Faces.TOP)

Faces.TOP chooses the face to open. It is different from Anchor.TOP, which chooses a relative placement reference. See the source and regression tests for the supported feature chains.

Position without hard-coded global offsets

from scpf import X, Y, Boss, Anchor

boss = Boss(d=7, h=12, hole_d=2.5).attach(
    case, parent=Anchor.INNER_BOTTOM,
    offset=(X.MIN + 10, Y.MAX - 10),
)

X.MIN and Y.MAX refer to the parent bounds and are not rotation-axis constants. Anchoring support currently focuses on rectangular bases and a documented set of faces. Do not assume every curved or lofted surface supports it.
