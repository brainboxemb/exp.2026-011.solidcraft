Negative circle profile extrusion

1. Test setup

Test goal

Qualify Circle2D authored inside an explicit Sketch and an explicitly selected negative extrusion direction with one minimal native model.

Pass criteria

One 20 mm diameter cylindrical body spans X/Y -10..10 mm and Z -30..0 mm, with an error-free saved SolidCraft timeline.

2. Implementation under test

Fixture source

"""Qualification: explicitly sketched Circle2D extrusion in negative Z."""


class NegativeCircleExtrude:
    diameter = 20.0
    height = 30.0

    def build(self):
        with Sketch(plane="XY") as sketch:
            Circle2D(d=self.diameter)
        return sketch.extrude(
            self.height,
            direction=Direction.NEGATIVE,
        )


NegativeCircleExtrude()

Public Forge API used

with Sketch(plane='XY'): Circle2D(d=20); sketch.extrude(30, direction=Direction.NEGATIVE)

Forge model represented by this fixture

One circular 2D profile authored in an explicit XY Sketch and extruded 30 mm along negative Z; no CSG or attachment is involved.
